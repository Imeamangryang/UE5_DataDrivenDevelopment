# Unreal Engine의 기본적인 구조

Unreal Engine에서 게임 세계를 구성하는 가장 상위의 개념은 World입니다.
World는 현재 실행 중인 게임 세계 전체를 관리하는 객체이며, 게임 안에 존재하는 모든 시스템과 객체들을 포함합니다.

World 내부에는 하나 이상의 Level이 존재합니다.

Level은 게임 세계를 구성하는 공간 단위입니다. 지형, 조명, 오브젝트 배치와 같은 실제 맵 데이터들이 Level 안에 저장되며, Unreal Engine은 여러 개의 Level을 동적으로 로드하거나 스트리밍하여 거대한 월드를 구성할 수 있습니다.

그리고 각 Level 내부에는 여러 개의 Actor가 존재합니다.

Actor는 게임 세계에 배치될 수 있는 가장 기본적인 객체입니다. 플레이어 캐릭터, 몬스터, 카메라, 아이템, 트리거와 같은 대부분의 게임 오브젝트들은 Actor 형태로 존재합니다.

하지만 Actor 자체가 모든 기능을 직접 가지고 있는 것은 아닙니다. 실제 기능들은 대부분 Component를 통해 구성됩니다.
