# Enhanced Input System

Unreal Engine에서 Data Asset이 실제로 활용되는 대표적인 시스템 중 하나가 Enhanced Input System입니다. Enhanced Input System은 기존의 입력 처리 방식보다 훨씬 더 유연하고 확장 가능한 구조를 제공하여, 게임 개발자들이 다양한 입력 장치와 복잡한 입력 로직을 효과적으로 관리할 수 있도록 설계되었습니다.

![](../assets/Pasted%20image%2020260526101112.png)

Enhanced Input System은 Input Action, Input Mapping Contect, Input Modifier, Input Trigger와 같은 4가지 주요 요소로 구성되어 있습니다. 이를 통해 입력 처리 로직을 데이터 중심으로 설계하여, 입력 설정을 코드와 분리하여 관리할 수 있도록 지원합니다.


## Input Action

Input Action은 플레이어가 수행하는 특정 행동을 나타내는 데이터 구조입니다. 예를 들어, "Jump", "Fire", "Move"와 같은 행동이 Input Action으로 정의될 수 있습니다. Input Action은 입력 이벤트가 발생했을 때 어떤 행동이 트리거되는지를 정의하는 역할을 합니다.

![](../assets/Pasted%20image%2020260526101722.png)

Input Action은 액션의 이름, 값 유형 등을 포함하는 데이터 구조로 정의됩니다. 이를 통해 개발자는 입력 이벤트가 발생했을 때 어떤 행동이 수행되어야 하는 지를 명확하게 정의할 수 있습니다.

## Input Mapping Context

Input Mapping Context는 Input Action과 실제 입력 장치의 버튼이나 축을 연결하는 데이터 구조입니다. 

예를 들어, 

- Input Action "Jump" : Space Bar
- Input Action "Fire" : Left Mouse Button
- Input Action "Move" : WASD

와 같이 Input Action과 실제 입력 장치의 버튼이나 축을 매핑하는 역할을 합니다.

![](../assets/Pasted%20image%2020260526102318.png)

Input Mapping Context를 이용하면 플레이어가 사용하는 입력 장치에 따라 유연하게 입력 설정을 변경할 수 있습니다. 예를 들어, 키보드와 마우스를 사용하는 플레이어와 게임패드를 사용하는 플레이어가 동일한 Input Action을 사용하지만, 각각 다른 버튼이나 축으로 매핑할 수 있습니다.

또한 Input Mapping Context는 상황에 따라 동적으로 전환할 수 있습니다. 
예를 들어, 플레이어가 차량을 운전할 때는 운전 모드에 맞는 Input Mapping Context로 전환하고, 보통 플레이 상태에서는 일반적인 Input Mapping Context를 사용할 수 있습니다. 이를 통해 게임의 다양한 상황에 맞게 입력 설정을 유연하게 관리할 수 있습니다.


## Input Modifier

Input Modifier는 입력 이벤트가 트리거되기 전에 입력 값을 수정하는 역할을 합니다. 입력 값의 범위를 제한하거나, 입력 값을 스케일링하는 등의 작업을 수행할 수 있습니다.

예를 들어, 플레이어가 WASD 키를 눌러 캐릭터를 이동할 때, 입력값의 축을 바꾸거나 부호를 반전시키는 등의 작업을 Input Modifier로 처리할 수 있습니다. 이를 통해 입력 이벤트가 트리거되기 전에 입력 값을 원하는 형태로 변환하여 사용할 수 있습니다.

## Input Trigger

Input Trigger는 입력 이벤트가 트리거되는 조건을 정의하는 역할을 합니다. 버튼이 눌렸을 때, 버튼이 떼어졌을 때, 일정 시간 동안 버튼이 눌렸을 때 등의 트리거 조건을 정의할 수 있습니다.

![](../assets/Pasted%20image%2020260526103925.png)

![](../assets/Pasted%20image%2020260526104139.png)

Input Trigger를 사용하면 입력 이벤트가 발생하는 조건을 세밀하게 제어할 수 있습니다. 

예를 들어, 플레이어가 버튼을 짧게 눌렀을 때는 일반 공격이 트리거되고, 버튼을 길게 눌렀을 때는 강력한 공격이 트리거되는 등의 다양한 입력 이벤트를 구현할 수 있습니다.
