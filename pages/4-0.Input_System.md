
# Input System

이 장에서는 Unreal Engine에서 데이터를 정의하고 저장하는 데 사용되는 Data Asset에 대해 먼저 살펴보겠습니다.

이후에는 Unreal Engine에서 새롭게 도입된 Enhanced Input System에 대해 알아보겠습니다. Enhanced Input System은 기존 입력 시스템보다 높은 확장성과 데이터 기반 설계를 제공하며, 입력 처리 로직을 `Input Action`과 `Input Mapping Context`라는 데이터 중심 구조로 분리하여 관리할 수 있도록 설계되었습니다.

본 장에서는 Enhanced Input System의 구조와 동작 방식을 이해하고, 왜 이 시스템이 Data-Driven Development 관점에서 중요한지 살펴보겠습니다.
