# UObject

UObject는 Unreal Engine의 기본이 되는 객체로, 단순한 C++ 클래스와는 달리 Unreal Engine의 다양한 시스템과 통합되어 동작하는 특별한 클래스입니다. 엔진 내부의 다양한 기능들은 대부분 UObject를 기반으로 구현되어 있으며, 게임에서 사용되는 대부분의 객체들도 UObject를 상속하여 만들어집니다.

대표적으로 다음과 같은 기능들이 UObject를 통해 제공됩니다.

- Reflection System
- Garbage Collection
- Serialization
- Blueprint Scripting
- Network Replication



# Reflection System

Reflection System은 Unreal Engine이 객체의 정보를 런타임에서 추적하고 접근할 수 있도록 하는 시스템입니다.

일반적인 C++ 클래스는 컴파일이 완료되면 런타임에서 클래스의 구조나 멤버 변수에 대한 정보를 알 수 없습니다. 하지만 UObject는 Reflection System을 통해 런타임에서도 클래스의 정보에 접근할 수 있습니다.

> C++ 26에서 도입된 Reflection 기능과는 별개로, Unreal Engine은 자체적인 Reflection System을 구현하여 UObject와 함께 사용합니다.

이를 통해 엔진에서는 객체의 클래스 이름, 멤버 변수, 함수 등에 대한 정보를 런타임에서 동적으로 조회할 수 있게 됩니다.

```cpp
UCLASS()
class MYGAME_API AMyActor : public AActor
{
	GENERATED_BODY()
	
public:
    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    int32 MyValue;
    
    UFUNCTION(BlueprintCallable)
    void MyFunction();
}
```

여기서 UCLASS, UPROPERTY, UFUNCTION과 같은 매크로들은 UHT에 의해 처리되어 클래스에 대한 메타데이터 정보를 생성하고 이를 generated.h 파일에 포함시킵니다.
생성된 메타데이터 정보는 객체의 정보를 엔진이 인식할 수 있도록 도와주는 역할을 합니다. 

이를 통해 런타임으로 실행되는 에디터의 Blueprint에서는 MyValue 변수에 접근하거나 MyFunction 함수를 호출할 수 있게 됩니다.
