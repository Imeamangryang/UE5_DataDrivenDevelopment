# 언리얼 엔진 이해하기

이 장에서는 Unreal Engine의 기본적인 구조와 핵심 시스템들에 대해 살펴보겠습니다. 
앞서 설명한 것처럼 게임 엔진도 결국 데이터들을 쉽게 처리하고 가공하기 위한 하나의 도구입니다.

데이터 주도 개발을 제대로 이해하기 위해서는 먼저 Unreal Engine이 어떤 구조 위에서 동작하는지 이해하는 과정이 필요합니다. 시스템이 객체를 어떤 방식으로 관리하는지, 데이터가 어떻게 저장되고 연결되는지, 그리고 게임 세계가 어떤 구조로 구성되는지를 이해해야 이후의 데이터 기반 설계를 더욱 자연스럽게 이해할 수 있기 때문입니다.

따라서 이 장에서는 Unreal Engine의 기본적인 계층 구조와 주요 시스템들을 함께 살펴보며, 이후 데이터 중심 구조를 설계하기 위한 기초 개념들을 알아보려 합니다.

- Unreal Engine의 기본적인 구조
- UObject와 Reflection 시스템
- GameFramework
