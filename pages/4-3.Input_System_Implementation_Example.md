# 입력 시스템 구현 예제

이제 Unreal Engine에서 데이터를 저장하는 방식 중 하나인 Data Asset과 Enhanced Input System에 대해 알아보았으니, 이를 활용하여 간단한 입력 시스템을 구현해보도록 하겠습니다.

먼저 입력 시스템과 Gameplay Tag를 연결하기 위한 Data Asset을 만들어보겠습니다. 이 Data Asset은 각 입력 액션이 어떤 Gameplay Tag와 연결되는 지를 정의할 것입니다.

> Gameplay Tag는 문자열 기반의 계층형 식별자 시스템으로, Unreal Engine에서 다양한 시스템 간의 상태와 이벤트를 데이터 중심으로 관리하기 위해 사용됩니다.  

## Gameplay Tag 정의

먼저 프로젝트에서 사용할 Gameplay Tag를 정의하겠습니다.

아래와 같이 입력 시스템에서 사용할 Gameplay Tag를 선언합니다.

```cpp
#pragma once  
  
#include "NativeGameplayTags.h"  
  
namespace InputGamePlayTags  
{  
    UE_DECLARE_GAMEPLAY_TAG_EXTERN(InputTag_Action_Move);  
  
    UE_DECLARE_GAMEPLAY_TAG_EXTERN(InputTag_Action_MouseLeft);  
    UE_DECLARE_GAMEPLAY_TAG_EXTERN(InputTag_Action_MouseRight);  
    UE_DECLARE_GAMEPLAY_TAG_EXTERN(InputTag_Action_MouseMiddle);  
}
```

이후 `.cpp` 파일에서 실제 Gameplay Tag를 정의합니다.

```cpp
#include "InputGamePlayTags.h"  
  
namespace InputGamePlayTags  
{  
    UE_DEFINE_GAMEPLAY_TAG(InputTag_Action_Move, "Input.Action.Move");  
  
    UE_DEFINE_GAMEPLAY_TAG(InputTag_Action_MouseLeft, "Input.Action.MouseLeft");  
    UE_DEFINE_GAMEPLAY_TAG(InputTag_Action_MouseRight, "Input.Action.MouseRight");  
    UE_DEFINE_GAMEPLAY_TAG(InputTag_Action_MouseMiddle, "Input.Action.MouseMiddle");  
}
```

Gameplay Tag는 일반적으로 다음과 같은 계층 구조로 구성합니다.

![](../assets/Pasted%20image%2020260526110319.png)

또한 Gameplay Tag를 입력 시스템과 함께 사용하면 단순히 “어떤 키가 눌렸는가”를 처리하는 것이 아니라, “어떤 행동(Action)이 발생했는가”를 기준으로 시스템을 설계할 수 있게 됩니다.

예를 들어 마우스 좌클릭이 공격인지 상호작용인지는 상황에 따라 달라질 수 있습니다. 하지만 입력 시스템에서는 단순히 `Input.Action.MouseLeft`라는 행동만 전달하고, 실제 동작은 다른 시스템에서 처리하도록 분리할 수 있습니다.

이는 입력과 게임 로직 사이의 결합도를 낮추고, 보다 유연한 Data-Driven 구조를 만드는 데 큰 도움이 됩니다.

## Input Config Data Asset 정의

이제 입력 시스템과 Gameplay Tag를 연결하는 `Input Config Data Asset`을 정의해보겠습니다.

앞서 설명했듯이 Enhanced Input System은 `Input Action`을 중심으로 동작합니다. 하지만 실제 게임 로직에서는 단순히 Input Action 자체보다는 “어떤 행동이 발생했는가”를 기준으로 처리하는 경우가 많습니다.

예를 들어 입력 시스템에서는 `IA_Move`라는 Input Action이 존재하더라도, 실제 게임 코드에서는 이를 `Input.Action.Move`라는 Gameplay Tag 기반으로 처리하는 것이 더 유연한 구조가 됩니다.

이를 위해 이번에는 Input Action과 Gameplay Tag를 서로 연결하는 Data Asset을 정의하겠습니다.

```cpp
#pragma once  
  
#include "CoreMinimal.h"  
#include "Engine/DataAsset.h"  
#include "GameplayTagContainer.h"  
#include "InputConfig.generated.h"  
  
class UInputAction;  
  
USTRUCT(BlueprintType)  
struct FTaggedInputAction  
{  
    GENERATED_BODY()  
  
public:  
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)  
    TObjectPtr<const UInputAction> InputAction = nullptr;  
  
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)  
    FGameplayTag InputTag;  
};  
  
UCLASS()  
class UE5_DDD_API UInputConfig : public UDataAsset  
{  
    GENERATED_BODY()  
    public:  
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)  
    TArray<FTaggedInputAction> InputActions;  
  
    const UInputAction* FindInputActionByTag(const FGameplayTag& InputTag) const;  
};
```

`FTaggedInputAction` 구조체는 다음 두 가지 데이터를 함께 저장합니다.

| 변수            | 설명                                     |
| ------------- | -------------------------------------- |
| `InputAction` | 실제 Enhanced Input System의 Input Action |
| `InputTag`    | 해당 Input Action과 연결될 Gameplay Tag      |

현재는 하나의 Input Action이 어떤 Gameplay Tag와 연결되는 지를 데이터 형태로 정의하는 구조입니다.

이를 통해 다음과 같은 매핑이 가능해집니다.

|Input Action|Gameplay Tag|
|---|---|
|IA_Move|Input.Action.Move|
|IA_MouseLeft|Input.Action.MouseLeft|
|IA_MouseRight|Input.Action.MouseRight|

`UInputConfig`는 이러한 매핑 정보를 배열 형태로 저장하는 Data Asset 역할을 수행합니다.

또한 `FindInputActionByTag()` 함수를 통해 특정 Gameplay Tag에 대응되는 Input Action을 검색할 수 있도록 구현합니다.

```cpp
#include "InputConfig.h"  
#include "InputAction.h"  
  
const UInputAction* UInputConfig::FindInputActionByTag(const FGameplayTag& InputTag) const  
{  
    for (const FTaggedInputAction& Action : InputActions)  
    {       if (Action.InputAction && Action.InputTag.MatchesTagExact(InputTag))  
       {          return Action.InputAction;  
       }    }    UE_LOG(LogTemp, Warning, TEXT("InputAction not found for tag [%s] in InputConfig [%s]"), *InputTag.ToString(), *GetNameSafe(this));  
    return nullptr;  
}
```

`FindInputActionByTag` 함수는 내부 배열을 순회하면서 전달받은 Gameplay Tag와 일치하는 Input Action을 찾아 반환합니다.
