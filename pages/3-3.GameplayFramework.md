
# Gameplay Framework


![](../assets/Pasted%20image%2020260519142102.png)

Unreal Engine에서 게임을 개발하기 위해 필요한 핵심적인 클래스들을 통틀어 Gameplay Framework라고 부릅니다.
게임의 **규칙**, **플레이어 제어**, **캐릭터**, **네트워크 동기화**, **UI** 등을 역할별로 분리하여 관리할 수 있도록 설계된 Unreal Engine의 핵심 클래스들입니다.

언리얼 엔진은 대부분의 게임 로직을 이 프레임워크 위에서 동작하도록 설계하고 있으며,  
프로젝트가 커질수록 Gameplay Framework의 각 클래스들을 올바르게 이해하고 사용하는 것이 매우 중요해집니다.
