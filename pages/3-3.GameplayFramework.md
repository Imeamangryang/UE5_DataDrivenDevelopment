
# Gameplay Framework


![](../assets/Pasted%20image%2020260519142102.png)

Unreal Engine에서 게임을 개발하기 위해 필요한 핵심적인 클래스들을 통틀어 Gameplay Framework라고 부릅니다.
게임의 **규칙**, **플레이어 제어**, **캐릭터**, **네트워크 동기화**, **UI** 등을 역할별로 분리하여 관리할 수 있도록 설계된 Unreal Engine의 핵심 클래스들입니다.

언리얼 엔진은 대부분의 게임 로직을 이 프레임워크 위에서 동작하도록 설계하고 있으며,  
프로젝트가 커질수록 Gameplay Framework의 각 클래스들을 올바르게 이해하고 사용하는 것이 매우 중요해집니다.

---
## GameMode

GameMode는 게임의 규칙과 설정을 관리하는 클래스입니다.

- 플레이어 로그인/로그아웃 처리
- 플레이어 스폰 관리
- 게임 승패 조건 관리
- 게임 라운드 관리

등의 역할을 담당합니다.

## GameState

GameState는 게임의 상태를 관리하는 클래스입니다.

- 플레이어 목록 관리
- 서버 상태 복제
- 서버 시간 동기화
- 관전자 클래스 관리

등의 역할을 담당합니다.

## Player Controller

Player Controller는 플레이어의 입력과 제어를 관리하는 클래스입니다.

- 플레이어 입력 처리
- Pawn 제어
- HUD 관리
- Camera Manager 관리

등의 역할을 담당합니다.

## Pawn

Pawn은 게임 세계에서 플레이어가 조작하는 캐릭터나 오브젝트를 나타내는 클래스입니다.

Player Controller를 통해 제어되는 객체로

- Character
- Vehicle
- Object

등 다양한 형태로 구현될 수 있습니다.

혹은 한 Player Controller가 여러 개의 Pawn을 제어하는 형태로도 구현될 수 있습니다.

## Player State

Player State는 플레이어의 상태 정보를 관리하는 클래스입니다.

- 플레이어 이름
- 점수
- ID
- 관전자 여부
- 봇 여부
- 핑

등의 정보를 관리합니다.

## HUD

HUD는 플레이어의 화면에 표시되는 UI 요소를 관리하는 클래스입니다.

Player Controller에서 소유하고 있는 클래스로

- 텍스트
- 도형
- 텍스쳐
- 머티리얼
- 디버그 드로잉
- 히트박스 이벤트

등 다양한 요소를 화면에 표시하는 역할을 담당합니다.

> 현재는 대부분 UMG로 UI를 구현하기 때문에 HUD 클래스의 역할이 많이 축소되거나 UserWidget의 생성 및 관리 정도로만 사용되는 경우가 많습니다.
