# Data Asset

Data Asset은 특정 시스템에서 사용하는 데이터를 독립적인 Asset 형태로 저장하기 위한 UObject 기반 클래스입니다.

![](../assets/Pasted%20image%2020260526100006.png)

Data Asset은 Blueprint나 C++ 클래스에서 정의된 구조체나 클래스를 기반으로 만들어질 수 있으며, 게임에서 사용하는 설정값, 테이블 데이터, 입력 설정, 아이템 정보, 스킬 데이터 등을 코드와 분리하여 저장하기 위한 목적으로 설계되었습니다.

이를 통해 다양한 설정 값이나 게임에서 사용되는 데이터들을 코드와 분리하여 독립적인 Asset으로 관리할 수 있게 됩니다.


## Data Asset의 특징

| 특징                   | 설명                                                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 독립적인 Asset 파일로 관리    | Data Asset은 콘텐츠 브라우저에서 독립적인 `.uasset` 파일로 존재합니다. 따라서 특정 Actor나 Blueprint에 종속되지 않으며, 여러 시스템에서 공통 데이터로 참조할 수 있습니다.           |
| Blueprint와 C++ 모두 지원 | Data Asset은 `UObject` 기반으로 동작하기 때문에 Blueprint와 C++ 양쪽에서 모두 쉽게 접근하고 사용할 수 있습니다.                                             |
| 다른 Asset 참조 가능       | Texture, Sound, Mesh, Animation Blueprint 등 다른 Unreal Engine Asset을 직접 참조할 수 있습니다. 이를 통해 데이터와 리소스를 함께 관리할 수 있습니다.          |
| 에디터에서 직접 수정 가능       | Data Asset은 Unreal Editor 내부에서 직접 열어 값을 수정할 수 있습니다. 코드를 수정하지 않고도 데이터를 변경할 수 있기 때문에 디자이너, 기획자, 아티스트도 쉽게 데이터를 관리할 수 있습니다.    |
| 런타임에서도 데이터 변경 가능     | Data Asset은 런타임에도 접근할 수 있으며, 상황에 따라 데이터를 동적으로 변경하여 사용할 수 있습니다. 이를 통해 입력 설정 변경, 밸런스 조정, 상태 기반 설정 전환 등의 기능을 유연하게 구현할 수 있습니다. |
