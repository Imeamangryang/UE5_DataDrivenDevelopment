# 언리얼 엔진 5 데이터 주도 개발

이 책은 게임 프로그래밍을 시작하면서 데이터를 다루는 방법에 대해 고민하는 사람들을 위해 쓰기 시작한 책이다. 

게임을 개발하다 보면 우리는 수많은 데이터를 다루게 된다.
기본적인 사용자의 입력 정보, 캐릭터의 능력치, 아이템 정보, 스킬 테이블, 퀘스트 조건, 애니메이션 상태, UI, 네트워크 동기화 데이터까지.
처음에는 단순한 이동과 공격으로 시작했던 프로젝트도 규모가 커질수록 복잡한 데이터들의 흐름 속에서 게임 개발자들의 정신을 어지럽게 한다.

이 책은 그런 어지러움을 한 번 즈음은 경험해 본 사람들에게 도움이 되었으면 하는 바램으로 작성을 시작했다.

목표는 Unreal Engine 5를 기반으로 데이터 주도 개발(Data-Driven Development)의 개념과 실제 활용 방법을 다루는 것이다. 단순히 Data Table 사용법만 설명하는 것이 아니라, 왜 데이터 기반 구조가 필요한지, 실제 게임에서는 어떤 방식으로 데이터가 연결되고 관리되는지, 그리고 이를 어떻게 확장 가능한 시스템으로 설계할 수 있는 지를 함께 이야기하려 합니다.
