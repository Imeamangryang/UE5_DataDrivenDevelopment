# 목표 구조

```
Physical Input
    ↓
Input Mapping Context
    ↓
Input Action
    ↓
Gameplay Tag
    ↓
Input Config
    ↓
Custom EnhancedInputComponent
    ↓
PlayerController
```

목표
- Enhanced Input System의 소개
- Input Action과 Input Mapping Context
  - Data Asset으로의 설계
- Context Switching
- Runtime Input Binding과 Unbinding (키 변경 UI도 구현)
- Input Recoding 시스템
